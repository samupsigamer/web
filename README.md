# Modelo Web 4 · Completo · Versión B

Web estática lista para subir a GitHub Pages. No necesita servidor ni framework.

## Subida a GitHub
1. Crea/abre tu repositorio.
2. Sube **todo el contenido de esta carpeta** manteniendo `assets/` y sus subcarpetas.
3. Ve a **Settings → Pages**.
4. En *Build and deployment* selecciona **Deploy from a branch**.
5. Elige `main` y `/ (root)`.
6. Guarda y espera a que GitHub Pages publique la web.

## Contacto
Edita `config.js`:
- `whatsapp`: número en formato internacional, solo dígitos. Ejemplo: `34600123456`
- `email`: tu correo.
- `instagram`: `samu.psigamer`

## Personajes
La carpeta `assets/chibis/` contiene 15 PNG independientes:
saludo, alegria, pensativo, tablet, dormido, leyendo, gaming, bloques, abrazo,
dibujando, celebrando, triste, calma, explorando y saludando.

Puedes sustituir cualquiera de ellos por otro PNG manteniendo el mismo nombre.

## Recursos
Los filtros de Gaming, Psicología, Infancia y Familias funcionan sin servidor.
Para añadir artículos reales, cambia los `href="#"` de `index.html` por las rutas de tus páginas/PDFs.

## Personalización
La web usa únicamente HTML, CSS y JavaScript, por lo que es compatible con GitHub Pages.
