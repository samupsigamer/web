# Modelo Web 4 · Versión B

Web estática lista para GitHub Pages.

## Estructura
- `index.html`
- `styles.css`
- `script.js`
- `config.js`
- `assets/images/*.svg`

## Elegir la imagen de cada sección
Hay dos formas:

1. **En la propia web:** cada sección tiene un selector "Imagen de esta sección".
2. **Para dejar una opción fija al publicar:** edita `config.js` y cambia:
   - `sobreMi`
   - `servicios`
   - `recursos`
   - `contacto`

Valores: `laptop`, `headset`, `tablet`, `reading`.
